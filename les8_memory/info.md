**Работа Garbage Collector в JavaScript**

Объекты очищаются, когда на них не остаётся ссылок.

**Алгоритмы управления памятью**

- Mark-Sweep: Помечает живые объекты и очищает непомеченные.
- 3ColorMark: Инкрементальный алгоритм с пометкой объектов тремя цветами для эффективного удаления.
- Stop&Copy: Сокращение фрагментации памяти путём копирования активных объектов в новую область.

**Оптимизации V8**

Разделение на пространства:

1. Молодое пространство (Nursery, Intermediate) для новых объектов.

2. Старое пространство для объектов, переживших несколько сборок мусора.

**Алгоритмы для разных пространств:**

Young: Parallel Scavenger для быстрого перехода и очистки.

1.  Mark
2.  Copy
3.  Update pointer

Old: Mark-Sweep для более глубокой и инкрементальной очистки.
